# IRAQ CUSTOMS — برنامج إدارة داخلي (الإصدار الثاني)

تطبيق جديد بالكامل للشركات والنقل والوثائق الداخلية والسائقين والتجار، مهيأ للجوال والآيباد. **ليس تابعاً للحكومة العراقية ولا يصدر وثائق رسمية**.

## الجديد
- يبدأ **بلا أي أرصدة أو قبوضات أو مستندات مالية**. لم ننقل حسابات الإصدار السابق.
- دليل عام يضم 839 شركة مسترجعة من الموقع السابق.
- إضافة وثيقة حمولة داخلية مع مبلغ بالدولار (يسمح بصفر).
- تسجيل قبض للتاجر مرتبط بالشركة اختياريًا.
- كشف حساب مع رصيد متسلسل وفلاتر التاجر والشركة والطباعة كـ PDF من المتصفح.
- دليل السائقين، اختيار الشركات، سلة محذوفات للوثائق والقبوضات.
- تصدير واستيراد نسخة احتياطية JSON، وإعادة تعيين البيانات المحلية.
- تصميم RTL مع 6 عناصر تنقل ثابتة بأسفل شاشة الجوال.

## التشغيل
لا توجد حزم أو أوامر بناء.
- للتجربة: \`python3 -m http.server 8080\` وافتح \`http://localhost:8080/\`.
- للنشر عبر Cloudflare Pages: اربط مستودع GitHub، الإطار \`None\`، أمر البناء **فارغ**، ومجلد الخرج \`.\`.
- ملفات المصدر الأساسية: \`index.html\`، \`assets/app.mjs\`، \`lib/model.mjs\`، \`assets/style.css\`، \`data/companies.json\`.
- الاختبارات: \`node --test tests/*.test.mjs\`.

## التخزين والخصوصية
- التخزين **داخل localStorage للمتصفح الحالي فقط**. لا يوجد Backend ولا مصادقة ولا مزامنة عبر الأجهزة.
- لا ترفع ملفات نسخ JSON المحاسبية إلى المستودع العام.
- لا تضع مفاتيح Cloudflare أو الرموز في JavaScript.
- نسخة الحسابات القديمة على Cloudflare منفصلة؛ لم يتم حذفها ولا نسخها.
- لا تعتمد على هذه النسخة وحدها للمحاسبة الاحترافية متعددة المستخدمين: تحتاج D1 وخادم مصادقة وتدقيق مالي ونسخاً احتياطية دورية.
- عند الحذف من الواجهة يتم نقل الوثائق والقبوضات إلى السلة. اختيار «مسح البيانات المحلية» يمسح كل بيانات V2 **من الجهاز الحالي**.
- عند تغيير الجهاز أو مسح بيانات Safari يمكن فقدان الحسابات؛ استخدم زر تنزيل نسخة احتياطية.

## الاستقلال عن الإصدار القديم
هذه **إعادة بناء من الصفر في مستودع raq-customs**؛ آخر نسخة من الإصدار السابق تبقى متاحة في سجل Git، لكن ملفاتها ليست ضمن الإصدار الحالي. موقع \`iraq-customs.pages.dev\` لا يتغير حتى تعيد ربطه ونشر هذا المستودع بنفسك.
